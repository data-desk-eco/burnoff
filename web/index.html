burnoff

Burnoff is an experiment in distributed detection and analysis of gas flaring at LNG terminals using Sentinel-2 satellite data, hosted by Data Desk. It also aims to be a useful tool for researchers, journalists and others monitoring the activities of the fossil fuel industry.

Click Detect to download and process Sentinel-2 satellite data for the current view, sharing the workload — and syncing the results — with connected peers via WebRTC. Click any detection to view the underlying data and flare analysis, and compare to VIIRS Nightfire data using VNF mode.
